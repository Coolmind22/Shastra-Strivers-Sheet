# Question 1:  Check Whether a Number Is Even or Odd
## Problem Statement Given an integer N, determine whether the number is even or odd. A number is considered even if it is completely divisible by 2; otherwise, it is odd.

Input
A single integer N.

Output
Print "Even" if the number is even; otherwise, print "Odd".

Example 1
Input:
8
Output:
Even

Example 2
Input:
7
Output:
Odd
